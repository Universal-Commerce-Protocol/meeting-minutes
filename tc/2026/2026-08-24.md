## 2. Open Discussions & PR Reviews

- **Topic:** Payment Namespace Standardization
  - **Notes:** The council discussed the directory structure and namespace conventions for payments to ensure consistent adoption across the ecosystem. Agreed on consolidating all payment-related extensions and types under a common payments namespace (dev.up.com.payments) and moving the payment JSON object to the common types directory, necessitating updates to core shopping services.
  - **Context:** [Payments Namespace and Common Types Shuffling](https://github.com/Universal-Commerce-Protocol/ucp/issues/520)
- **Topic:** Tokenizer Binding Polymorphism and Extensibility
  - **Notes:** Reviewed PR 746 regarding tokenizer updates and checkout ID binding. Discussed the polymorphic token binding updates in PR 746, agreeing that closing the structure is acceptable for the current requirements while continuing to audit the PR's dependencies and linters.
  - **Context:** [PR #746 polymorphic token binding](https://github.com/Universal-Commerce-Protocol/ucp/pull/746)
- **Topic:** Constraint Pull Requests
  - **Notes:** Greg Smith and Daniel Wyckoff reported that the constraint PRs are in a good position, with feedback on PR 424 resolved and stacked for merging. Ilya Grigorik confirmed they will perform a second review pass on PR 757 and review PR 424 to move the merge process forward.
  - **Context:** [Express instrument requirements with request constraints, split PAN and Network Token credential types](https://github.com/Universal-Commerce-Protocol/ucp/pull/424)
- **Topic:** Cleanup and Refactoring PRs

Niranjan Manjunath confirmed they are actively working on moving shopping extensions and will ping the technical committee channel for reviews once the PR is ready.
