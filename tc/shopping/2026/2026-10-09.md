# UCP Shopping Tech Council (STC) Meeting - 2026-10-09

**Led by:** Amit Handa

## Attendance

- **Present:** Amit Handa, Daniel Wyckoff, Drew Olson, Ilya Grigorik, Patrick Jordan, Prasad Wangikar

## 1. General Topics

- **Topic:** UCP Summit Attendance and Payments Technical Council Inclusion
  - **Notes:** Amit Handa announced that 32 participants have confirmed attendance for the upcoming Universal Commerce Protocol (UCP) Summit in November. Drew Olson confirmed that members of the newly formed Payments Technical Council (PTC) were invited, noting an attendee update regarding Simon for harsh that requires separate follow-up.
  - **Context:** [Universal-Commerce-Protocol/ucp](https://github.com/Universal-Commerce-Protocol/ucp)
- **Topic:** International Representation and Domain Working Group Scoping
  - **Notes:** Amit Handa proposed sponsoring regional domain working groups (DWGs) outside the United States to address growing international demand. Ilya Grigorik supported the initiative, emphasizing strong pull from Latin America, India, and Europe, and cautioned that failing to engage risks third parties creating fragmented, parallel protocols.
  - **Discussion:** Drew Olson cautioned against creating an unfocused non-US catch-all group and advocated scoping specific regional mechanisms such as Pix and Unified Payments Interface (UPI). Drew Olson, Ilya Grigorik, and Amit Handa agreed to establish a tightly constrained, one-month scoping milestone consisting of four weekly meetings to define concrete problem sets before seeking re-approval from the Governance Council and Payments Technical Council.
  - **Decision:** The group agreed to establish an initial one-month milestone of four meetings for the regional domain working group to scope and agree on problem sets.
- **Topic:** Bonus Deep Dives and Food Domain Technical Council Draft Pull Request
  - **Notes:** Amit Handa noted that Greg Smith circulated an availability poll for bonus technical council deep dive sessions scheduled for Wednesday and Thursday. Amit Handa reported that the lodging vertical team published their first draft pull request, and the Food Domain Technical Council (DTC) published its first draft pull request, which shares common primitives with payments and requires review ahead of Governance Council approval next week.
  - **Context:** [feat: Introduce Food Checkout Capability and Fulfillment Extension](https://github.com/Universal-Commerce-Protocol/ucp/pull/897), [feat: Introduce Lodging Booking Capability and Cancellation Policy Extension](https://github.com/Universal-Commerce-Protocol/ucp/pull/780)

## 2. Open Discussions & PR Reviews

- **Topic:** Nonprofit Donation Platforms Integration
  - **Notes:** Prasad Wangikar presented a proposal to integrate nonprofit donation platforms into UCP, addressing use cases such as agentic discovery of niche charities, nonprofit trust verification, anti-money laundering checks, and global tax receipt delivery.
  - **Discussion:** Ilya Grigorik explored how donation inventory and discovery map to agentic commerce patterns. Amit Handa and Prasad Wangikar discussed governance placement across the shopping and payments technical councils, concluding that members should evaluate whether the proposal constitutes an extension of shopping or a distinct vertical domain.
- **Topic:** Main Branch Test Recovery and Webhook Signing Documentation
  - **Notes:** Ilya Grigorik presented pull request 919 resolving a `main` branch regression where schema table regression tests failed due to an obsolete `allOf` branch blocking bundled schema type recovery.
  - **Discussion:** Amit Handa highlighted community pull request 659 regarding webhook IDs and timestamps in the request signing gate, requesting peer reviews from council members with available bandwidth.
  - **Context:** [fix(docs): restore bundled schema type recovery](https://github.com/Universal-Commerce-Protocol/ucp/pull/919), [fix(order)!: cover webhook-id and webhook-timestamp in the signing gate](https://github.com/Universal-Commerce-Protocol/ucp/pull/659)
- **Topic:** Ask Capability Release and In-Flight Shopping PRs
  - **Notes:** Amit Handa congratulated the council on merging pull request 538 for the `ask` capability, which introduces natural-language Q&A to bridge beyond static catalogs, carts, and checkouts. Amit Handa encouraged final reviews on open pull requests, including email-based identity linking and SDK intermediate generation tooling.
  - **Discussion:** Ilya Grigorik reported ongoing work on the return policy extension (pull request 634), noting discussions on how much structured data merchants can reliably guarantee prior to order placement. Amit Handa noted merchants can supply minimum baseline guarantees to prevent overpromising.
  - **Context:** [feat: `ask` capability for natural-language Q&A](https://github.com/Universal-Commerce-Protocol/ucp/pull/538), [feat(identity-linking): allow email matching when the IdP is the DNS-delegated authoritative email issuer](https://github.com/Universal-Commerce-Protocol/ucp/pull/876), [feat: add return policy extension (dev.ucp.shopping.policy.return)](https://github.com/Universal-Commerce-Protocol/ucp/pull/634), [feat: migrate model generation to ucp-schema generate-types](https://github.com/Universal-Commerce-Protocol/js-sdk/pull/87)
- **Topic:** Purchase Options Extension and Subscription Policy Consolidation
  - **Notes:** Daniel Wyckoff summarized updates to the purchase options extension, reporting that pull request 901 was closed and combined into a single unified extension carrying subscription policies underneath.
  - **Discussion:** Daniel Wyckoff noted ongoing iterations to clarify payment terms and split payment mechanics, with an updated draft pull request scheduled to open by Monday. Amit Handa urged council members to provide proactive approvals and visible validation when they have no major design objections.
  - **Context:** [feat: add purchase options extension (dev.ucp.shopping.purchase_options)](https://github.com/Universal-Commerce-Protocol/ucp/pull/901), [feat: add purchase options extension (dev.ucp.shopping.purchase_options)](https://github.com/Universal-Commerce-Protocol/ucp/pull/890)
- **Topic:** UI Over Wire via A2UI and Model Context Protocol Apps
  - **Notes:** Amit Handa presented early design sketches for delivering dynamic user interface representations directly over the wire using Agent-to-User Interface (A2UI) components and Model Context Protocol (MCP) apps, reducing the platform-side burden of building bespoke UIs for every new capability.
  - **Discussion:** Ilya Grigorik questioned whether UCP needs to hard-spec UI presentation layers given evolving industry standards, noting larger platforms often require strict presentation tree control while scoped capabilities like `ask` provide cleaner boundaries. Amit Handa confirmed the proposal intentionally uses lightweight bindings to existing specifications and agreed to prototype the concept.
  - **Context:** [feat: add UI extension with A2UI and MCP Apps bindings](https://github.com/Universal-Commerce-Protocol/ucp/pull/899)
- **Topic:** Catalog Search Extensions for Recommendations and Product Swaps
  - **Notes:** Amit Handa presented pull request 902 proposing the addition of `purpose` and `reference_ids` fields to catalog search to handle item recommendations and product swaps via existing search infrastructure.
  - **Discussion:** Ilya Grigorik compared the approach to Shopify's global catalog query extensions and queried whether swaps and recommendations require distinct semantic handling. Amit Handa argued that swaps demand exact product replacements whereas recommendations serve broader merchandising, inviting members to test the draft implementation.
  - **Context:** [feat(catalog): add purpose and reference_ids to catalog search](https://github.com/Universal-Commerce-Protocol/ucp/pull/902)
